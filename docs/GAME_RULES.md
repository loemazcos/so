# 태산의 폰 — 게임 규칙 (이 문서가 다른 설명보다 우선한다)

## 세계관과 기술 규칙
이 프로젝트는 "태산의 폰"이라는 한국어 인터랙티브 로맨스 게임이다. 플레이어는 보넥고등학교 1학년 여학생 태산의 아이폰을 직접 쓴다. 모든 장면은 폰 화면 안에서 일어난다(교실 장면 없음).

[세계관 — 절대 어기지 말 것]
- 학교는 "보넥고등학교"뿐이다. 날짜는 2026년 10월. D1=10/14(수), 축제=D15=10/28(수), D21=11/3. 5월 표기는 박람회(5/29)와 과거 기록에만 쓴다.
- 인물: 태산(1학년, 플레이어, 여), 상혁(2학년 탁구부), 동현(1학년, 태산 남사친), 재현(2학년 전교회장), 성호(2학년 선도부장). 운학은 없다.
- 생일: 재현 12/04, 동현 10/20, 상혁 10/22, 성호 10/04, 태산 08/10.
- 인물은 모두 고등학생이다. 로맨스는 설렘, 손잡기 수준까지만. 성적인 내용과 신체 묘사는 절대 쓰지 않는다.

[기술 규칙]
- 스택: Vite + React + TypeScript + Tailwind + lucide-react + Supabase. `@/`는 src/, `@data/`는 data/.
- 게임 상태, 단서, 메시지는 `device_id`(브라우저에 저장된 랜덤 UUID)별로 저장한다.
- 브라우저는 Supabase 테이블을 직접 읽거나 쓰지 않는다. 모든 읽기/쓰기는 Edge Function을 통한다. Anthropic API 키는 Edge Function 환경변수에만 있고 코드, 채팅, 커밋에 쓰지 않는다.
- AI 모델 이름은 환경변수 ANTHROPIC_MODEL(기본값 claude-haiku-5-5)로 읽는다.
- 이모지는 UI에 쓰지 않고 lucide 아이콘을 쓴다. 한글 폰트 스택: -apple-system, "Apple SD Gothic Neo", "Noto Sans KR".
- 화면 기준은 390x844 아이폰. 다크모드는 게임 시각(19:00~06:00) 기준으로 자동 전환.
- 새 외부 패키지는 꼭 필요할 때만 쓴다. 소리는 WebAudio 합성으로 만들고 음원 파일을 쓰지 않는다.

[작업 방식]
- 내가 한 번에 한 단계씩 요청한다. 요청받은 범위만 바꾸고, 이미 있는 폰 껍데기(잠금화면, 홈, 제스처, 알림센터, 컨트롤센터)는 망가뜨리지 않는다.
- 데이터는 data/ 폴더의 .js 파일에 두고, 초보자가 고칠 수 있게 주석을 한국어로 단다.
- 각 단계가 끝나면 무엇을 바꿨는지 5줄 이내로 요약한다.

### 2-1. 하루의 구조와 시간
- 게임 시계는 **행동으로만** 흘러요. 실시간으로 흐르지 않아요.
- D1만 **21:47**에 시작해요. D2부터는 아침 **07:00**에 시작해요.
- 낮(08:00~16:00)은 학교예요. 폰은 **쉬는 시간 3번**(10:00, 12:30, 15:00, 각 10분)에만 쓸 수 있어요. 그 사이는 "수업 중" 화면이에요.
- 새벽 02:00~05:00까지 깨어 있으면 상혁의 현활과 새벽 메시지를 볼 수 있어요. 대신 **다음 날 쉬는 시간 1번이 사라져요**(졸음).
- 22:00 이후에 "잠들기" 버튼이 나와요. 누르기 전에 **충전기 연결** 여부를 골라요.

**대화 구분**
- 1:1 대화(상혁, 동현, 재현, 성호)와 상담은 모두 **인스타 DM**에 있어요.
- 카톡에는 단톡방(1학년 3반, 탁구부 단톡, 보넥 밴드)과 나와의 채팅만 있어요.

**행동별 소모 (분 / 배터리 %)**
| 행동 | 시간 | 배터리 |
|---|---|---|
| 앱 열기 | 1 | 0.5 |
| DM 방 열기 / 보내기 | 1 / 1 | 0.2 |
| 카톡 방 열기 | 2 | 0.3 |
| 인스타 피드 스크롤 1회(게시물 5개) | 5 | 2 |
| 스토리 한 사람 | 2 | 1 |
| 릴스 5개 | 10 | 5 |
| 메모 하나 읽기 | 1 | 0.1 |
| 통화 (음성 없이 자막으로 진행) | 자막 1줄당 게임 시간 20초 | 분당 1.5 |
| 알림센터 열어 미리보기 | 0 | 0 |

### 2-2. 배터리
- D1 시작 62%. 20% 이하 **저전력**(알림이 30분 늦게 오고 화면이 어두워져요). 0%에서 **꺼짐**.
- 충전기를 꽂고 자면 아침 배터리가 100%예요. 안 꽂고 자면 아침에 **-10%**예요.
- 0%로 꺼지면 다음 날 07:00에 5%로 시작하고, 그날 새벽 알람이 울리지 않아요. 밤사이 온 알림은 한꺼번에 쌓여 있어요.
- **통화 중 0%가 되면** 끊겨요. 마음 -10. 충전기를 꽂고 **5분(게임 시간) 안에 다시 걸면** 만회돼요.
- 통화는 배터리 8% 이상일 때만 받을 수 있어요.

### 2-3. 메시지 규칙
- 상태: 보냄 → 전달됨 → **읽음**. 읽음은 상대가 앱에서 그 대화방을 열었을 때만 떠요.
- 태산이 읽은 뒤 **24시간(게임 시간)** 안에 답하지 않으면 **읽씹 +1**이에요.
- 상혁의 답장 지연 (마음 기준)
  - 80 이상: 1~5분
  - 60~79: 낮 5~20분, 밤 15~60분
  - 40~59: 30~120분
  - 40 미만: 읽씹 위주
- 입력 연출: "입력 중 2.5초 → 사라짐 → 4초 후 다시 입력 중 → 도착". `typing_cycles`로 몇 번 반복할지 정해요.
- 전송 취소: 인스타 한국어 UI의 **"전송 취소"** 문구를 써요. 대화방에는 `상혁님이 메시지를 전송 취소했습니다`만 남아요.
- **알림센터 트릭**: 푸시 알림은 전송 취소돼도 원문이 남아요. 대화방을 열면 그 알림은 사라져요. 알림센터에서 길게 눌러 미리보기를 보면 **읽음이 아니에요**.
- **활동 상태 표시**: 설정에서 켜고 끌 수 있어요. 켠 채로 읽고 24시간 답하지 않으면 읽씹 +1에 **마음 -2**를 더해요. 끄면 마음 감점이 없어요.

### 2-4. 변수와 시작값
용기 **20**, 상혁 마음 **60**, 소문 **10**, 읽씹 0, 친밀도 동현 5·재현 5·성호 1.

**용기 예산 (상담표 값 기준으로 다시 계산했다)**
| 출처 | 용기 |
|---|---|
| 시작 | 20 |
| 동현 상담 (회차별: S1 6, S2 6, S3 8, S4 10, S5 10, S6 8, S7 8) | 선택한 회차의 값 |
| 메모 18번 해제 | +10 |
| 알람 이름 바꾸기 | +8 |
| 송금 받기 | +4 |
| 탁구 복식에 "나갈게요" (3회, 회당 +5) | +15 |
| D14 "이제 답해도 돼요?" | +10 |
| 성호 2단계 신청서 | +3 |

D 엔딩은 **동현 S5(먼저 연락)와 S6(이제 답해도 돼요?)이 필수**이고 재현 상담이 2회 이상 필요해서, 그 경로의 최소 상담 용기는 18이에요.
최소 경로 합계 = 20 + 10 + 8 + 4 + 15 + 10 + 3 + 18 = **88**. D 기준은 **75**.
- 탁구를 한 번 빠지면 80(통과), 두 번 빠지면 72(탈락)예요. 한 번까지만 빠질 수 있어요.
- 숨기·거절 선택은 -3이에요.

### 2-5. 엔딩 판정 (위에서부터 먼저 맞는 것)
| 엔딩 | 조건 |
|---|---|
| **A-0 직진** | D1에 DM에 즉시 답장 |
| **D 진엔딩** | 메모 18 해제 + 단서 18개 이상(핵심 6개 포함) + 용기 75 이상 + 읽씹 2 이하 + S5 동현 "먼저 연락" + 동현·재현 각 2회 이상 상담 + 알람 변경 + D14 "이제 답해도 돼요?" |
| **A** | 통화 "받기" + 마음 70 이상 + 용기 40 이상 |
| **B** | 위에 못 닿은 모든 경우 (B1 통화 종료 / B2 방해금지 / B3 말 못 한 밤) |
| **C** | B 이후 한 달 뒤, 잠금 3개 퍼즐 후 선택 |

핵심 단서 6개: C02, C04, C13, C17, C19, C21.
**소문 폭주**: D14에 소문이 80 이상이면 마음 -10이에요. 성호 친밀도가 3 이상이면 성호가 정정 제보를 올려서 막아 줘요.

### 2-6. 인터랙션 공통 규칙 (v2)
- 숨은 수치(마음, 용기, 소문, 읽씹, 친밀도)는 화면에 숫자로 절대 보여 주지 않는다. 하루 정리 카드에는 읽씹 수만 보여 준다.
- 쓰다 지우기: 상혁 방 입력창에 글자를 넣었다가 전부 지우면 draftErase를 +1(방별). 한 방에서 3이 되면 flags.erasedThrice를 켠다.
- 방해금지: 켜 두면 알림 배너와 소리가 나오지 않고 알림센터에는 쌓인다. 읽씹 24시간 타이머와 읽음 규칙은 그대로 흐른다(악용 방지).
- 선택지의 효과 수치는 코드에 흩뿌리지 말고 data/story/ 아래 데이터 파일의 표에서 읽는다. 표에 없는 효과는 만들지 않는다.
